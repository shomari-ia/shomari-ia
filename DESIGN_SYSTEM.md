# Researcher Visual Identity — Gray Scientific Futurism v2.2 · Luminous Coral-Peach

Approved creative direction: **Shomari IA**.

## Palette

| Visual role | Color | Hex |
|---|---|---|
| Primary charcoal | Deep graphite | `#181B1D` |
| Secondary | Warm charcoal gray | `#27292B` |
| Primary typography | Metallic silver | `#E4E6E6` |
| Supporting typography | Cool neutral gray | `#B9BEC0` |
| Accent (sparing) | Luminous coral-peach | `#FF8975` |
| Highlight | Silver-white | `#FAFAF8` |

**Accent update:** vivid coral-peach `#FF8975` adds a subtle futuristic warmth against dark gray; use `#4A4D50` for readable graphite labels on light backgrounds.\n\n**Do not use bright blue, cyan, aquamarine, or green as a default branding accent.** Scientific plots may use meaningful scientific colors when essential to the data, with an accessible legend.

## Typography

**Georgia** is the primary font family for authored prose and narrative headings across the research portfolio, presentation decks, journal, posters, and exhibit materials. Keep text legible with generous spacing and coherent hierarchy. Use specialist mathematical fonts for equations and monospaced fonts for code, file paths, and reproducibility records.

GitHub's profile README is rendered using GitHub's own site fonts. A repository Markdown file cannot impose Georgia globally on visitors. The Georgia standard applies where document or webpage styling is controllable; preserve accessible, selectable text rather than converting all paragraphs to images.

## Signature design language

- Soft silver metallic gradients, brushed titanium effects, restrained coral-peach hairlines.
- Smooth waveforms, curved mathematical grids, signal traces, subtle axes, continuous surfaces, open negative space.
- No decorative honeycombs, hexagon carpets, or octagons.
- A graphene hexagon remains acceptable **only when needed to depict actual graphene chemistry**, where it must follow scientifically appropriate geometry.
- Personal visual brand displayed as **Shomari IA**. Formal name remains in academic citations, authorship, and official dissertation materials.

## Creative vs scientific material

- Brand illustration is **conceptual**. Do not present it as Gaussian-derived structures, trajectories, molecular geometry, or proof of validation.
- The GQD research repository remains the scientific source of truth. Personal profile artwork and AXIOM branding do not supersede acceptance gates or computational evidence.

## Application

Use this design direction for the personal GitHub profile, GQD repo branding, future research journal, posters, presentations, and Milestone 03 scientific iconography.

## Restricted accent tones

Maroon and dark-red tones are excluded from the visual identity. Do not reintroduce `#A74442`. Use neutral dark graphite (`#4A4D50`) for small text on light surfaces and luminous coral-peach (`#FF8975`) only as a bright accent against dark graphite backgrounds.
